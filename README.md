# Jerzy MX Analog Delay 2 VST3

Rozwojowa wersja MX Analog Delay 2 dla Windows/DAW. Dwa niezależne silniki A/B pracują jako Series, Parallel lub Split L/R.

Silniki obejmują: MultiHead Reel, Tape Echo, Oil Can, Tube Echo, BBD, Doubletrack, Dual Digital, Space Echo 202 oraz BBD Machine 101.

MX2 dodaje osobną pętlę efektów na torze wet: Chorus, Flanger, LoFi, Overdrive i Granular. LoFi może działać tylko na wet albo na wet + dry.

Wersja 2 ma nowy identyfikator VST3 i nazwę pliku JerzyMXAnalogDelay2.vst3, więc może współistnieć ze starszą wersją.

Integracja obejmuje synchronizację BPM z hostem, automatyzację parametrów VST3, MIDI mapping, spillover, skalowalne GUI oraz reset kontrolek prawym przyciskiem.

Optymalizacje obejmują przygotowywanie tylko aktywnego formatu sample 32/64-bit, redukcję alokacji w callbacku audio oraz normalizację poziomu w routingu równoległym i szeregowym.
